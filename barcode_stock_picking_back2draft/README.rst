This module exposes the existing ``stock_picking_back2draft`` action
from the Barcode picking screen for canceled pickings.

**Table of contents**

.. contents::
   :local:

Usage
=====

Open a canceled picking in Barcode and select **Back to draft**. After
the operation succeeds, Barcode returns to the picking list.
