1.  Configure which quality tests apply to which products for receptions: on the
    incoming operation type's quality trigger (created by
    quality_control_stock_oca), add trigger lines on the product, its template
    or its category pointing at the test to run.
2.  Assign operators to the *Barcode Stock Quality User* group so they can run
    inspections from the scanner.
3.  In the Barcode app, open a reception. If it has quality inspections, a
    **Quality** tab appears; answer each check and confirm.
4.  When an inspection does not pass, tap *Attach photo evidence* to add a photo
    to it.
