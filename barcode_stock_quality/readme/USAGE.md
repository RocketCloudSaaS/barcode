1.  Configure which quality tests apply to which products for receptions: on the
    incoming operation type's quality trigger (created by
    quality_control_stock_oca), add trigger lines on the product, its template
    or its category pointing at the test to run.
2.  Operators run inspections from the scanner with the same rights as in the
    back office: they need to be *Quality Control* users. Others see the
    **Quality** tab tell them so.
3.  In the Barcode app, open a reception. If it has quality inspections, a
    **Quality** tab appears; answer each check and confirm.
4.  Every question needs its answer; a measure left blank is not taken as 0.
    When an inspection does not pass, tap *Attach photo evidence* to add a
    photo to it (only images are taken).
5.  A confirmed inspection shows its answers read-only. If it was confirmed by
    mistake, tap *Back to draft* to reopen it and answer it again — unless a
    supervisor has already rejected it (*Failed*): that decision is theirs,
    and is not reopened from the scanner.
